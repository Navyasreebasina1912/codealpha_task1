# CodeAlpha Task 1 - Iris Flower Classification

Part of the CodeAlpha Data Science Internship (October Batch).

## Goal
Predict whether an iris flower is Setosa, Versicolor, or Virginica using its sepal and petal measurements.

## Steps
1. Loaded the Iris dataset from Scikit-learn
2. Checked the data and visualized it with a pairplot
3. Split the data into training and testing sets
4. Scaled the features with StandardScaler
5. Trained a Logistic Regression model
6. Evaluated it with accuracy, classification report, and confusion matrix

## Tools Used
Python, Pandas, Matplotlib, Seaborn, Scikit-learn

## How to Run
Open `iris_classification.ipynb` in Google Colab and run all cells from top to bottom.
